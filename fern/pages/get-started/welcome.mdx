Cohere builds world-class AI models:

- **[Command](../docs/command-a-plus)** for chat, RAG, tool use, and agents.
- **[North Mini Code](../docs/north-mini-code-1.0)** for agentic coding and software engineering tasks.
- **[Embed](../docs/cohere-embed)** for semantic search, classification, and clustering.
- **[Rerank](../docs/rerank)** for improving search relevance.

You can put these models to work through any of Cohere's products. This page helps you find the right
one for what you're building.

## Cohere products

Every product is powered by Cohere's models but meets a different need: from calling the model APIs
directly, to running them in a dedicated, isolated deployment, to adopting a ready-made AI assistant that does the work for you.

### Cohere Platform

**Best for getting started fast.** The Cohere Platform lets you call our models directly over the API
on Cohere's cloud, with no infrastructure to manage. Grab an API key and start
building in minutes.

- New here? Read the [platform overview](../docs/the-cohere-platform).
- [Install an SDK](../docs/get-started-installation) (Python, TypeScript, Java, or Go) and
  [create a client](../docs/create-client).
- Explore the [models](../docs/models) and the [API reference](../reference/about).

### Model Vault

**Best for security, isolation, and control.** [Model Vault](../docs/model-vault) deploys Cohere's
models in a dedicated, single-tenant environment, so your workloads run in isolation rather than on
shared infrastructure. You call it over the same API, without operating the serving stack yourself. For regulated or highly sensitive workloads,
[Model Vault Encrypted](../docs/model-vault/encrypted) adds confidential computing, so you can run
fully encrypted AI inference inside hardware-secured enclaves and cryptographically verify that
protection at any time through remote attestation.

[Explore Model Vault →](../docs/model-vault)

### North

**Best for a ready-to-use AI solution.** North is Cohere's **agentic AI platform**: a complete
application that puts the models to work for your team out of the box. Chat with a helpful AI
assistant, ground answers in your connected documents and data, create and refine documents, and
build customizable agents and workflow automations, with secure integrations to systems like Google
Drive, SharePoint, Slack, Salesforce, and MCP servers. North can be deployed and run in your own
environment (on-premises or air-gapped), with strong security, data, and compliance controls.

[Read the North documentation →](https://private.docs.cohere.com/north-documentation)

## Which should I use?

| If you want to… | Use |
|---|---|
| Get started fast with direct API access on shared infrastructure | [Cohere Platform](../docs/the-cohere-platform) |
| Deploy Cohere's models securely in a dedicated, isolated environment | [Model Vault](../docs/model-vault) |
| Run fully encrypted, verifiably private inference for your most sensitive or regulated workloads | [Model Vault Encrypted](../docs/model-vault/encrypted) |
| Adopt a ready-made agentic AI assistant that works over your internal data | [North](https://private.docs.cohere.com/north-documentation) |
