Once your Vault is set up in the dashboard, use the **Vault endpoint URL** and **model name** shown in
the model card (see [Managing Vaults](/docs/model-vault/managing-vaults)) in your API calls.

Point the Cohere SDK at your vault endpoint:

```python PYTHON
import cohere

co = cohere.ClientV2(
    api_key="<COHERE_API_KEY>",
    base_url="<YOUR_VAULT_ENDPOINT_URL>",
)

response = co.chat(
    model="<YOUR_VAULT_MODEL_NAME>",
    messages=[{"role": "user", "content": "Hello from Model Vault!"}],
)

print(response.message.content[0].text)
```

You'll authenticate with your Cohere API key, passed as `api_key` when you create the client.

This page is the **shared baseline** that applies to every vault. Encrypted vaults add an extra
verification step on top of this baseline, covered in
[Using the API with an Encrypted Vault](/docs/model-vault/encrypted/api-usage).

<Note>
For **Encrypted** vaults, the client also verifies the deployment's
[remote attestation](/docs/model-vault/encrypted/attestation) before sending data and fails closed on
mismatch. See [Verifying Your Deployment](/docs/model-vault/encrypted/verifying-deployment) and
[Using the API with an Encrypted Vault](/docs/model-vault/encrypted/api-usage).
</Note>

## Chat, Embed, and Rerank

The chat example above points the SDK at your vault. Embed and Rerank requests work the same way:
keep the `base_url` pointed at your vault endpoint and call `co.embed(...)` or `co.rerank(...)` with
your vault's model name.
