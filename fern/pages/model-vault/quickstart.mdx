This quickstart walks you through creating your first vault from the Cohere dashboard and making an
inference request against it. The same flow applies to every vault — the only choice is whether to
create a **Standard** or an **Encrypted** vault.

<Steps>
### Create a vault

In the [Cohere dashboard](https://dashboard.cohere.com/), open **Vaults** and create a new vault,
selecting a model and a performance tier. See [Creating a Vault](/docs/model-vault/creating-a-vault)
for the full walkthrough.

To create an **Encrypted** vault, enable the encrypted option during creation — see
[Encrypted Vaults](/docs/model-vault/encrypted).

### Get your endpoint and model name

Once the vault status is **Ready**, open its summary page and copy the **endpoint URL** and **model
name** from the model card. See [Calling a Vault over the API](/docs/model-vault/api-access).

### (Encrypted only) Verify the deployment

If you created an encrypted vault, confirm the environment is genuine and running the expected code
before sending data — see [Verifying Your Deployment](/docs/model-vault/encrypted/verifying-deployment).

### Make a request

Point the Cohere SDK at your vault endpoint and call it like any other Cohere model.

{/* TODO: add a verified, runnable code sample (Python/TypeScript/cURL) using the vault endpoint URL. */}

```python PYTHON
import cohere

co = cohere.ClientV2(
    api_key="<COHERE_API_KEY>",
    base_url="<YOUR_VAULT_ENDPOINT_URL>",
)

response = co.chat(
    model="<YOUR_VAULT_MODEL_NAME>",
    messages=[{"role": "user", "content": "Hello from Model Vault!"}],
)

print(response.message.content[0].text)
```
