Text watermarking embeds an invisible, machine-readable signal in text generated by in-scope Cohere
models, so the text can be detected as AI-generated. Watermarking is available for certain models to
support the marking requirements of Article 50(2) of the EU AI Act.

## Availability

Whether output is watermarked depends on where your vault is hosted:

- Vaults hosted in the EU serve only watermarked versions of in-scope models.
- Vaults hosted outside the EU serve only unwatermarked models.
- Output from the shared Cohere API isn't watermarked. If you provide an AI system in the EU and
  want watermarked output, use a vault hosted in the EU.
- API calls and responses do not change.

For regional availability, see [Model Vault regions](../../docs/model-vault/regions).

## Detection

You can request access to Cohere's watermark detection tool by contacting customer support.
Requests are reviewed before access is granted, and access is limited to certain types of verified
end users.

A negative detection result simply means that a Cohere watermark was not detected. It doesn't always
mean that the text was not AI-generated. Text may not carry a Cohere watermark if it was heavily
edited, too short, or generated by an unwatermarked model. Cohere's detection tool is only designed
to detect Cohere watermarks - watermarks from other providers will not be detected.
