Encrypted vaults use the same shared API baseline ([Calling a Vault over the API](/docs/model-vault/api-access)),
with one critical addition: the client **verifies the deployment's
[remote attestation](/docs/model-vault/encrypted/attestation) before sending any data** and fails
closed if verification does not pass. This page covers that attestation-verified client setup and the
behavior that's specific to Encrypted Vaults.
