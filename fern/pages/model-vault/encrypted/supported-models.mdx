## Architecture

Model Vault Encrypted builds on the isolated, single-tenant Vault architecture and adds
confidential-computing protections:

- **Logically isolated**: Isolates all infrastructure components, including the network load balancer, reverse proxy, serving middleware, inference servers, and GPU accelerators.
- **Confidential computing**: Inference runs inside hardware-backed trusted execution environments, so data stays protected **in use** — see the [Security Model](/docs/model-vault/encrypted/security-model) and [Confidential Computing Primer](/docs/model-vault/encrypted/confidential-computing).
- **Minimal shared components**: Shared infrastructure is limited to authentication and underlying Kubernetes/compute resources (nodes, CPU, and memory).
- **Cohere-managed operations**: Cohere handles maintenance, deployments, updates, and scaling.

<Note>
For how data is protected in transit, at rest, and in use, and how Zero Data Retention (ZDR) is
handled, see [Encryption & Key Management](/docs/model-vault/encrypted/encryption-key-management).
</Note>
