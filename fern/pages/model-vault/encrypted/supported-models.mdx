## Architecture

Model Vault Encrypted runs on the same isolated, dedicated, Cohere-managed infrastructure as a
[Standard Vault](../../../docs/model-vault/standard), and adds on top:

- **Confidential computing**: inference runs inside hardware-backed trusted execution environments (a confidential VM such as Intel TDX or AMD SEV-SNP on the CPU, and an NVIDIA GPU in confidential-computing mode), so data stays protected **in use**, not just in transit and at rest. See the [Security Model](../../../docs/model-vault/encrypted/security-model) and [Confidential Computing Primer](../../../docs/model-vault/encrypted/confidential-computing).

<Note>
For how data is protected in transit, at rest, and in use, and how Zero Data Retention (ZDR) is
handled, see [Encryption & Key Management](../../../docs/model-vault/encrypted/encryption-key-management).
</Note>

## Supported models

Encrypted Vaults run in the United States, with regional serving in the European Union and Canada
coming soon (see [Regions](../../../docs/model-vault/regions)). Every model below runs on one NVIDIA
H100 80GB GPU in confidential-computing mode.

### Cohere models

| Model family | Type |
| --- | --- |
| Embed | Embeddings |
| Rerank | Reranker |
| Parse | Vision parser |
| Compass | Embed + Rerank + Parse bundle |
| North Mini Code | Generative (code) |
| Cohere Transcribe | Speech recognition (ASR) |
| Customized Cohere models | Varies |

### Open models

An Encrypted Vault runs open models from the following families. The model catalogue shows the
specific models available when the Encrypted option is selected.

| Model family | Developer |
| --- | --- |
| Gemma | Google |
| GPT-OSS | OpenAI |
| Phi | Microsoft |
| Qwen | Alibaba |
| Ministral, Devstral | Mistral AI |

Open models are called through the OpenAI-compatible Chat Completions API. See
[Calling an Encrypted Vault over the API](../../../docs/model-vault/encrypted/api-usage#calling-open-models).

We are expanding this support over time, including larger models, so availability can differ from a
[Standard Vault](../../../docs/model-vault/standard/supported-models). To confirm availability for a specific
model, check the model catalogue when [creating a vault](../../../docs/model-vault/creating-a-vault) with the
Encrypted option selected, or contact Cohere.

## Supported GPUs

Encrypted Vaults run on confidential-computing-capable NVIDIA H100 GPUs. To confirm the
options available for your model, capacity, and region, contact Cohere.

Encrypted Vaults are priced per GPU, per hour. See the [pricing page](https://cohere.com/pricing).
