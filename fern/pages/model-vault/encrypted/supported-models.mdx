## Architecture

Model Vault Encrypted builds on the isolated, single-tenant Vault architecture and adds
confidential-computing protections:

- **Logically isolated**: isolates all infrastructure components, including the network load balancer, reverse proxy, serving middleware, inference servers, and GPU accelerators.
- **Confidential computing**: inference runs inside hardware-backed trusted execution environments (Intel TDX on the CPU and an NVIDIA GPU in confidential-computing mode), so data stays protected **in use**. See the [Security Model](/docs/model-vault/encrypted/security-model) and [Confidential Computing Primer](/docs/model-vault/encrypted/confidential-computing).
- **Minimal shared components**: shared infrastructure is limited to authentication and underlying Kubernetes/compute resources (nodes, CPU, and memory).
- **Cohere-managed operations**: Cohere handles maintenance, deployments, updates, and scaling.

<Note>
For how data is protected in transit, at rest, and in use, and how Zero Data Retention (ZDR) is
handled, see [Encryption & Key Management](/docs/model-vault/encrypted/encryption-key-management).
</Note>

## Supported models

Encrypted Vaults support the following models:

| Model | Type |
| --- | --- |
| Embed v3, v4, v5 | Embeddings |
| Rerank v3.5, v4, v5 | Reranker |
| Compass Bundle | Embed + Rerank + Vision Parser |
| North Mini Code | Generative (code) |
| Cohere Transcribe | Speech recognition (ASR) |
| Customized Cohere models | Varies |

The models above are what we support in the Model Vault Encrypted **beta**, and we are expanding this support over
time, so availability can differ from a
[Standard Vault](/docs/model-vault/standard/supported-models). To confirm availability for a specific
model, check the model dropdown when [creating a vault](/docs/model-vault/creating-a-vault) with the
Encrypted option selected, or contact Cohere.

## Supported GPUs

Encrypted Vaults run on confidential-computing-capable NVIDIA GPUs. To confirm the
options available for your model, capacity, and region, contact Cohere.

For pricing per model and performance tier, see
[Model Vault Encrypted Pricing](/docs/model-vault/encrypted/pricing).
