The following Cohere models are available in a Standard Vault. For the deployment flow, see
[Creating a Vault](/docs/model-vault/creating-a-vault).

| Model | Type |
| --- | --- |
| Command A | Generative |
| Command A Reasoning | Generative |
| Command A Vision | Generative (multimodal) |
| Command A Translate | Generative |
| Command A+ | Generative |
| North Mini Code | Generative (code) |
| Embed v3, v4, v5 | Embeddings |
| Rerank v3.5, v4, v5 | Reranker |
| Compass Bundle | Embed + Rerank + Vision Parser |
| North Bundle | Generative + Compass Bundle |
| North Large | Bundle |
| Cohere Transcribe | Speech recognition (ASR) |
| Customized Cohere models | Varies |

<Note>
Embed and Rerank models are generally available self-serve. Generative models, bundles, speech, and
customized models may require a waitlist. Check the model dropdown when
[creating a vault](/docs/model-vault/creating-a-vault), or contact Cohere.
</Note>

## Supported GPUs

A Standard Vault can be deployed on a range of NVIDIA GPUs. To confirm the options available
for your model, capacity, and region, contact Cohere.

## Differences for Encrypted Vaults

Model and GPU availability differs for [Encrypted Vaults](/docs/model-vault/encrypted/supported-models),
since confidential computing depends on specific GPU hardware and each model must fit on a single GPU.

For pricing per model and performance tier, see [Pricing](/docs/model-vault/standard/pricing).
