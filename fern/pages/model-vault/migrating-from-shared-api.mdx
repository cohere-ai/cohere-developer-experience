Move workloads from the shared Cohere API (`api.cohere.com`) to a dedicated vault. The request and
response shapes are the same Cohere API you already use — in most cases you only repoint the SDK at
your vault endpoint and update the model name. This page walks through what changes, what stays the
same, and how to cut over safely.
