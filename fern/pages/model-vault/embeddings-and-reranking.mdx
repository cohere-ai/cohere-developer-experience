**Vault endpoint URL** and **model name** pattern described in
[Calling a Vault over the API](/docs/model-vault/api-access). This baseline applies to every vault; for
type-specific differences see
[Using the API with a Standard Vault](/docs/model-vault/standard/api-usage) or
[Using the API with an Encrypted Vault](/docs/model-vault/encrypted/api-usage).
