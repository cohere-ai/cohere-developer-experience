Automations let you define a sequence of steps an agent should take, specifying which
tools and data sources are appropriate for each step.

## Building an automation

1. Open **Automations** from the sidebar.
2. Select **+ New automation** to open the builder.
3. Add nodes one at a time — LLM nodes, conditional logic, human-in-the-loop review, and loops.
4. Connect each node so it can draw on the output of the previous one.
