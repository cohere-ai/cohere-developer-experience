Model Vault is a Cohere-managed inference environment for deploying and serving Cohere
models in an isolated, single-tenant setup. Each Vault runs in a dedicated environment
with network isolation and managed infrastructure.

<Note>
Prototype page — demonstrates Model Vault as its own top-level product with its own tabs.
</Note>

## Two ways to use Model Vault

- **Standalone**: Deploy models and call Model Vault endpoints directly.
- **With North**: Run North in your VPC/on-prem and route inference to Model Vault.
