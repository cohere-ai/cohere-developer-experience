Model Vault (Standalone) lets you deploy models in a dedicated inference environment from
the Cohere dashboard, without operating the underlying serving infrastructure.

## Setting up a standalone Vault

1. Sign in to `dashboard.cohere.com` and open **Vaults**.
2. Select **+ New Vault** and name it.
3. Choose model types (Chat, Embed, Rerank) and set min/max replicas.
4. The environment is provisioned with a unique subdomain, API endpoint, and monitoring dashboard.
